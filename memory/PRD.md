# The Camden Lane - Cafe Website

## Project Overview
A motion-rich, scroll-driven interactive website for "The Camden Lane" - a 2D theme cafe in Koregaon Park, Pune.

## Original Problem Statement
Create a website similar to Grandmama's Cafe (grandmamascafe.com) but for "The Camden Lane" cafe with:
- GSAP scroll animations
- 2D sketch/line-art aesthetic (black & white theme)
- Sections: Hero, About, Menu, Gallery, Contact
- No reservation/booking system
- Portfolio/demo website to present to cafe owner

## User Personas
- **Primary**: Young professionals, couples, Instagram-savvy diners in Pune
- **Secondary**: Cafe owner evaluating the website demo

## Core Requirements (Static)
- [x] Motion-rich, scroll-driven website using GSAP
- [x] Match Camden Lane's 2D sketch aesthetic
- [x] Hero section with animations
- [x] About Us story section
- [x] Menu showcase with placeholder dishes
- [x] Gallery section with interior/food photos
- [x] Contact/Location information
- [x] Mobile responsive design

## Tech Stack
- **Frontend**: React 19, Tailwind CSS, GSAP (ScrollTrigger)
- **Backend**: FastAPI (minimal - not heavily used for this static site)
- **Styling**: Custom CSS with Google Fonts (Amatic SC, Patrick Hand, Quicksand)
